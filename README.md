# 🐾 동물 친구로 알아보는 나의 성격 탐험대 (초등 저학년 MBTI)

초등학교 1~3학년 어린이들의 눈높이에 맞춘 인터랙티브 MBTI 심리테스트 웹앱입니다.

---

## 🌟 프로젝트 특징
- **맞춤형 20개 문항**: 학교생활, 쉬는 시간, 놀이터, 상상놀이 등 일상적인 상황 기반 (E/I, S/N, T/F, J/P 각 5문항).
- **16가지 동물 수호신 캐릭터**: 날다람쥐(ENFP), 골든리트리버(ENFJ), 사자(ENTJ), 코알라(ISFJ) 등 친근한 동물 매핑.
- **아동 친화적 UI/UX**: 동글동글한 파스텔 디자인, 바운스 애니메이션, 인터랙티브 폭죽(Confetti) 효과.
- **바이럴 & 공유 기능**: 카카오톡/SNS 공유 및 클립보드 링크 복사 지원.
- **수익화 슬롯 탑재**: 구글 애드센스(Google AdSense) 광고 배너가 들어갈 전용 슬롯 완비.

---

## 🚀 바로 실행하는 방법
1. 파일 탐색기에서 `index.html` 파일을 더블 클릭하여 크롬/엣지 등 브라우저로 바로 실행할 수 있습니다.
2. 로컬 서버로 실행하려면:
   ```bash
   npx serve .
   # 또는
   python -m http.server 3000
   ```

## 💰 AI 부업 수익화 및 배포 가이드

### 1단계: 1분 무료 웹 배포 (URL 생성)
- **Vercel / Netlify / GitHub Pages**를 이용하면 이 폴더 그대로 드래그 앤 드롭하여 전 세계 누구나 접속할 수 있는 무료 웹사이트 주소(`https://my-kids-mbti.vercel.app` 등)를 얻을 수 있습니다.

### 2단계: 트래픽 유입 (바이럴 전략)
- **맘카페 / 초등 학부모 커뮤니티**: "아이 성향 파악에 좋은 초등 저학년 맞춤 동물 성격 테스트 공유해요!" 글로 자연스럽게 유입.
- **카카오톡 단체방**: 학부모 모임, 아이들 친구 단톡방에 공유 유도.

### 3단계: 수익화 (Google AdSense 연동)
- `index.html` 하단의 `.ad-slot-box` 영역에 발급받은 애드센스 디스플레이 광고 코드만 복사해 넣으면, 유입되는 트래픽에 따라 지속적인 광고 수익이 발생합니다.
